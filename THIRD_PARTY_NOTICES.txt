The production build ships the following third-party code in a separate file,
assets/libheif-bundle-*.js, which is loaded only when the browser cannot decode
a HEIC photo itself. That file is libheif-bundle.mjs from the npm package
libheif-js, minified by the bundler but otherwise unchanged; the WebAssembly
binary inside it is byte for byte the published one. It is a separate module
and can be replaced with another build of the same library.
